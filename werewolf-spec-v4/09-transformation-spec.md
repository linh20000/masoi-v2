# 09 — Transformation Specification

Transformation thay đổi Role/Alignment/Ability set.

## Cases
| Source | Trigger | Result |
|---|---|---|
| Wild Child | idol dies | Werewolf |
| Wolf-Dog | setup variant | Villager/Werewolf |
| Wolf-Dog | bitten variant | Werewolf |
| Angel | objective failed | Villager |
| Actor | after allowed nights | Villager |
| Devoted Servant | execution event | victim role |
| Shadow | target dies | target role |
| Father of Werewolves | wolf victim | Werewolf |

Mỗi transformation phải có condition, source state, target state, side effects và event.
